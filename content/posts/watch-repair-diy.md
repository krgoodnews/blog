# 상황

한 남자는 기존에 보유하고 있던 시계들을 다시 보게 됐다. 애플워치를 더 이상 메인으로 착용하지 않게 되었기 때문이다.

# 문제

5개 중 3개의 시계가 동작하지 않는다. 시계의 배터리가 모두 멈췄기 때문이다. 시계를 착용하지 않은지 오랜 시간이 지났기 때문이다.

# 해결과정

1. 시계 수리 공구를 샀다. 7600원으로 생각보다 저렴했다.
    - 공구는 쿠팡에서 구매했다 ([LINK](https://www.coupang.com/vp/products/5047910069?vendorItemId=74097560102&sourceType=MyCoupang_my_orders_list_product_title&isAddedCart=))
2. 시계 뒷판을 공구로 열어 필요한 배터리 종류를 파악했다.
    - 유명한 시계는 인터넷 검색으로 알 수 있었지만, 유명하지 않은 시계는 유저 매뉴얼에도 나와있지 않다.
        - Briston Clubmaster: SR927W / LR57 (호환)
        - Casio MDV-106(흑새치): SR626SW / LR66
        - Dissel: SR920SW / LR69
3. 다이소에서 LR66, LR69 배터리를 구입해 교체했다.
4. LR57은 인터넷으로 구매했다. Renata 배터리가 좋다고 해서 구매했다. ([LINK](http://itempage3.auction.co.kr/DetailView.aspx?ItemNo=B279520200&frm3=V2))

# 성과

1. 배터리가 방전된 3개 중 2개의 배터리 교체에 성공했다.
2. 우레탄 줄이 끊어진 시계의 새로운 줄과 Face를 구매했다. (지샥 GD-100GB)

# 후기

여러개 할거 아니면 시계방 가자.
