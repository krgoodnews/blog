# [Plan] 알고리즘 이론 포스트 통폐합 및 태그 체계 개선

## 1. 개요
현재 `content/알고리즘-이론/` 디렉토리에 범용성이 낮거나 특정 문제에 지나치게 종속된 이론 포스트들이 많아, 이를 관련 문제 포스트로 통합하거나 삭제하여 지식 체계를 간소화합니다.

- **대상**: 중요도 ⭐1~⭐3 포스트 (11개)
- **목표**: 중복 제거, 문제 중심의 지식 전달, 이론 디렉토리 정예화

## 2. 상세 계획
### Phase 1: 포스트 병합 (Merge)
이론적 가치가 있으나 특정 문제의 핵심 원리인 경우, 해당 문제 포스트의 '이론' 또는 '핵심 아이디어' 섹션으로 내용을 옮깁니다.
- `longest-increasing-subsequence.md` -> `boj-11053.md`
- `coordinate-compression.md` -> `boj-18870.md`
- `grid-path-count-dp.md` -> `leetcode-62-unique-paths.md`
- `grid-connected-components.md` -> `boj-1012.md`
- `word-pattern-bijection.md` -> `leetcode-290-word-pattern.md`

### Phase 2: 포스트 삭제 (Delete)
다른 상위 이론(DFS/BFS/DP)에서 충분히 다루고 있거나, 단순 문제 풀이 팁인 경우 삭제합니다.
- `memoization.md` (DP로 통합)
- `connected-components.md` (DFS/BFS로 설명 가능)
- `python-input-optimization.md` (범용 팁)
- `set-contagion-tracking.md` (문제 풀이 종속)
- `set-intersection.md` (문제 풀이 종속)
- `set-session-tracking.md` (문제 풀이 종속)

### Phase 3: 후속 작업
- 삭제된 포스트를 참조하고 있는 다른 문서의 링크 수정
- `content/알고리즘-이론/index.md` 목록 업데이트

## 3. 기대 효과
- **가독성 향상**: 학습자가 이론과 문제를 한 번에 이해할 수 있음
- **관리 효율성**: 파편화된 문서 관리 비용 감소
- **검색 최적화**: 핵심 알고리즘 위주의 인덱싱 강화
