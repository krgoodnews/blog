# [Design] 알고리즘 이론 포스트 통폐합 상세 설계

## 1. 개요
중요도 ⭐1~⭐3 수준의 이론 포스트 11개를 정리하여 중복을 제거하고 지식의 응집도를 높입니다.

## 2. UI/UX 시각화 (포스트 구조 변경)
병합 후의 문제 포스트는 다음과 같은 구조를 가집니다.

```text
+---------------------------------------+
| [Title] BOJ 11053: 가장 긴 ...        |
+---------------------------------------+
| > [!note] 이론 요약 및 핵심 아이디어    |
+---------------------------------------+
| 1. 문제 (지문, 입력, 출력, 예제)        |
+---------------------------------------+
| 2. 문제 분석 (핵심 포인트)              |
+---------------------------------------+
| 3. 해결 방법 (점화식, 로직 설명)        |
+---------------------------------------+
| 4. 코드 구현 (Python/C++ 등)           |
+---------------------------------------+
| 5. 심화 이론 (기존 이론 포스트 병합분)   |  <-- NEW (이론 포스트의 핵심 내용)
|    - O(n log n) 최적화 방법 등         |
+---------------------------------------+
| 6. 관련 알고리즘 및 링크               |
+---------------------------------------+
```

## 3. 상세 병합 및 삭제 로직

### A. 병합 대상 (Merge)
| 소스 (이론) | 대상 (문제) | 병합할 핵심 내용 |
| :--- | :--- | :--- |
| `longest-increasing-subsequence.md` | `boj-11053.md` | O(n log n) 최적화 방법, LIS 활용 사례 |
| `coordinate-compression.md` | `boj-18870.md` | 좌표 압축의 개념과 왜 필요한지에 대한 설명 |
| `grid-path-count-dp.md` | `leetcode-62-unique-paths.md` | 조합론적 접근법 ($nCr$) 설명 |
| `grid-connected-components.md` | `boj-1012.md` | 격자 상에서의 인접 행렬 vs 인접 리스트 차이 |
| `word-pattern-bijection.md` | `leetcode-290-word-pattern.md` | Bijection(전단사 함수) 개념 설명 |

### B. 삭제 대상 (Delete) - 내용이 상위 이론에 포함됨
- `memoization.md` (DP 포스트로 통합 권고)
- `connected-components.md` (DFS/BFS 포스트로 통합 권고)
- `python-input-optimization.md` (삭제 후 필요시 별도 Tips 카테고리로 이동)
- `set-*.md` 시리즈 (문제 포스트 내 코드로 충분함)

## 4. 기술적 절차 (Do Phase)
1. **Content Extraction**: 이론 포스트에서 중복되지 않는 고유한 설명을 추출합니다.
2. **Post Update**: `replace` 또는 `write_file`을 사용하여 문제 포스트에 내용을 추가합니다.
3. **Reference Cleaning**: `grep_search`로 삭제 대상 파일을 참조하는 모든 파일을 찾아 링크를 수정합니다.
4. **File Removal**: `run_shell_command("rm ...")`으로 파일을 삭제합니다.

## 5. 검증 계획 (Check Phase)
- 모든 링크가 깨지지 않고 정상적으로 연결되는지 확인 (Quartz 빌드 테스트)
- `index.md`에서 삭제된 포스트가 노출되지 않는지 확인
